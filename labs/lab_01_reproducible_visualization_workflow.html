  Asthma_visits,

Create Vaccination Plot

vaccination_plot <- ggplot(county_health_data, 
            aes(
              x = reorder(County, Vaccination_rate),
              y = Vaccination_rate,
              fill = Vaccination_rate
            ))+
  geom_bar(stat = "identity")+
  geom_hline(
    yintercept = 0.80, 
    linetype = "dashed", 
    color = "purple"
    )+
  coord_flip()+
  scale_fill_gradient( 
    low = "lightpink",
    high = "hotpink"
    )+
  labs(
    x = "Ranked Counties",
    y = "Vaccine Coverage",
    title = "Counties Ranked by Simulated Vaccine Coverage",
    caption = "Horizontal bar chart ranking fictional counties by simulated vaccination coverage."
  )+ 
  theme(
    plot.caption = element_text(hjust = 0.5), legend.position = "none")

vaccination_plot

Reflection Questions

Answer each question in complete sentences.

Question 1

Why is reproducibility important in public health research and practice?

Response: Reproducibility allows research and practice methods to be verified through the production of the same results. Reproducibility is important in public health research and practice because it ensures health decisions and interventions made based on data is not due to chance or bias. It creates an avenue for science to be credible and honest, especially when creating solutions for underserved or vulnerable populations.

Question 2

How does a consistent project structure improve collaboration and review?

Response: A consistent project structure improves collaboration and review because it allows teams to efficiently understand the methods and data each team member used to get to a result. It eliminates the need for teams to have to guess or interpret the mechanisms of a project, which could introduce difficulty and unwanted bias. Consistent project structure is also important because it allows reviewers to catch mistakes in code and results early. Lastly, consistent project structure prevents teams from wasting time and financial resources.

Question 3

Why are relative paths preferable to absolute paths?

Response: Relative paths are preferable to absolute paths because they allow code and files to be shared while avoiding sharing errors or crashes. Relative paths allow projects to move between different computers and users without causing server breaks as a absolute path would. An example of this would be sending a professor a project that contains absolute paths, making it unable to run smoothly and display work. However if relative paths were used the project would run smoothly and have no display errors.

Question 4

How does GitHub contribute to reproducibility?

Response: GitHub contributes to reproducibility because it provides a centralized network for code and projects to be shared. In this sharing, anyone can access your code to review and re-run projects in order to verify and see results for themselves.

Question 5

What was the most challenging part of the lab?

Response: The most challenging part of the lab was pushing to Github for it to show up in my class repository. It was challenging mainly due to it being my first time pushing my R projects to GitHub, but I know overtime I will get better at it and therefore get it to push smoothly.
