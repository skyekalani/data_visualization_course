county_map_data <- county_map_data %>%

Part 7: Interactive Leaflet Map

county_leaflet <- county_map_data %>%
  st_transform(
    crs = 4326
  )

coverage_palette <- colorNumeric(
  palette = "viridis",
  domain = county_leaflet$vaccination_rate,
  na.color = "#BDBDBD"
)

county_labels <- paste0(
  "<strong>",
  htmlEscape(
    county_leaflet$county_name
  ),
  " County</strong>",
  "<br>Simulated vaccination coverage: ",
  round(
    county_leaflet$vaccination_rate,
    digits = 1
  ),
  "%",
  "<br>Simulated child population: ",
  scales::comma(
    county_leaflet$child_population
  )
) %>%
  lapply(
    HTML
  )
interactive_vaxmap <- leaflet(
  data = county_leaflet,
  options = leafletOptions(
    minZoom = 5
  )
) %>%
  addProviderTiles(
    providers$CartoDB.Positron
  ) %>%
  addPolygons(
    fillColor = ~coverage_palette(
      vaccination_rate
    ),
    fillOpacity = 0.8,
    color = "white",
    weight = 0.6,
    opacity = 1,
    label = county_labels,
    highlightOptions = highlightOptions(
      weight = 2,
      color = "#333333",
      fillOpacity = 0.9,
      bringToFront = TRUE
    )
  ) %>%
  addLegend(
    pal = coverage_palette,
    values = ~vaccination_rate,
    title = "Simulated coverage (%)",
    position = "bottomright",
    opacity = 0.8
  )

Part 8: Ethics and Accessibility

Discuss ecological interpretation, small cells, stigma, exact locations, missing data, and a noninteractive alternative.

Response: When creating static and interactive maps it is important to factor in ecological fallacy, small cells, stigma, exact locations, and missing data. Ecological fallacy can occur when ecological data is interpreted as an assumption of all statistical trends and characteristics being attributable to each individual within a given group. An example of this using the create interactive graphs is assuming each individual in Worth county, GA is vaccinated because they have a high simulated vaccination coverage. To prevent misleading results, it is important to make group analyses on ecological data rather than individual-level conclusions.

When creating maps it is also important to refrain from using small cell counts and exact locations of individuals. Including these features makes it easier to identify real individuals within a specific area, removing the privacy of their data. To ensure the privacy of individuals within the data it is important to use small cell size suppression and geographic masking, aggregation and other protections to ensure the data is ethical. Furthermore, small cell size suppression and other factors can create missing data in the map. When this occurs missing data should be clearly labeled and made a distinct color so viewers interpret them as missing values and not zero values.

When creating and interpreting a map it is important to refrain from stigmatizing specific communities. Stigmatizing a community can look like labeling a community as dangerous or mapping where things are going wrong in a community without giving further context. To limit this include descriptions that explain the context of map findings. Lastly, to ensure interactive maps are accessible including static maps and alternative text descriptions ensures all viewers are able to interpret the presented data.
