Reflection

Explain why long format was useful, what causes row multiplication during joins, and why rates are preferable to counts.

Response: Turning my data into long format is useful because it allows me to observe data under a single variable rather than multiple variables. In the context of my county health data, I used the long format to convert observations separated by multiple-year variables into a single variable. This mechanism is useful because it allowed me to create and analyze graphs more easily. Moreover, row multiplications occur when joining two datasets together, and each observation is not uniquely identified. This means that if one dataset has a duplicate key, when a join occurs, the duplicate key will appear more than once in the resulting joined dataset. To prevent this, check for and remove duplicates before joining datasets. Lastly, rates are preferable to counts because rates account for group size when doing comparisons. For instance, in my county health data, case rates account for county population size, whereas the count of cases does not. Ultimately, using rates allows for better comparison of groups regardless of size and enables true patterns across groups to be understood rather than mistaken.
